# CODA + GITHUB OPERATING PROTOCOL
VERSION: 1.1.0

Coda is the shared control plane; GitHub is the technical artifact vault. Both Projects should have the same verified access where supported.

Assistant Coda uses: project lookup/state reconciliation; control-plane writes; requirement/decision updates when established; handoff/persistence audit.

Assistant GitHub uses: artifact/version lookup; manifest/reference verification; latest-release verification.

Neither connector is assumed to intercept every ChatGPT message.
