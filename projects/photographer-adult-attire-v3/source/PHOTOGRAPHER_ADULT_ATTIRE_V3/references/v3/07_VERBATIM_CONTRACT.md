# VERBATIM EDIT + TARGET CONTRACT

The USER EDIT REQUEST is the actual request to the image editor.

It is immutable for transmission:
- exact wording retained;
- no summary;
- no paraphrase;
- no shortening;
- no omission;
- no reordering.

The SOURCE-LOCKED TARGET RECONSTRUCTION is a separate full-text artifact describing the intended final state of the same source image after the authorized edit.

ACTUAL EDITOR PAYLOAD:
A. Source image
B. Complete user edit request, verbatim
C. Complete source-locked target reconstruction, full text

A, B, and C must all be transmitted.
