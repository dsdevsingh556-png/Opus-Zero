# OPUS ZERO — Inter-Agent Contract Kit
VERSION: 1.2.0

What most “two bots” setups lack: a published interface.

## Included
1. `HANDOFF_TEMPLATE.md` — copy-ready handoff
2. `STATE_AUTHORITY.md` — evidence ranking
3. `CONTRADICTION_CHECKLIST.md` — failure-closed checks
4. `BUILDER_MODE_GATE.md` — Reader default + one-shot approval

Use with any Assistant/Builder pair. OPUS ZERO is the reference implementation.
